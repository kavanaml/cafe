# Brew Haven Coffee ☕

## About the Project
Brew Haven Coffee is a coffee shop website
designed to provide customers with an
attractive and user-friendly experience.

## Features
- Home page
- Coffee menu page
- Contact page
- Navigation between pages
- Attractive styling

## Technologies Used
- HTML
- CSS

## Project Pages
- index.html – Home page
- menu.html – Menu page
- contact.html – Contact page
- style.css – Website styling

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html in a browser.
